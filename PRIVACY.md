# Privacy Policy for LIC Robotics Sync

Effective date: October 7, 2026

LIC Robotics Sync is a file synchronization application created for members of LIC Robotics Club. This policy explains what information the app handles and where it is stored.

## Information handled by the app

The app handles the following information when it is used:

- the selected student profile and its repository folder identifier;
- the names and contents of robotics project files selected by the user;
- synchronization history needed to identify changed or deleted files; and
- access information for the local folder selected through the iPadOS Files picker.

The selected profile, local folder access information, and pending synchronization state are stored locally on the iPad.

## GitHub synchronization

When a user chooses **Push Changes**, the app sends project filenames, project contents, the selected student's folder identifier, and a synchronization commit message to the LIC Robotics Club GitHub repository. The repository is public, and its contents and commit history may be viewed or downloaded by anyone.

When a user chooses **Pull Updates**, **Check Status**, or opens **Team Files**, the app requests the relevant project information from GitHub.

GitHub processes this information according to the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Users must not place passwords, private documents, contact information, or other sensitive personal information in synchronized project files or filenames.

## Data use

Information is used only to provide file synchronization, backup, project history, and teammate project-sharing features. The app does not use advertising, behavioral tracking, analytics SDKs, or sell personal information.

## Retention and deletion

Files remain in the GitHub repository until they are deleted. Deleting and pushing a file removes the current repository copy, but earlier versions may remain in Git commit history. A parent, guardian, or club organizer may request help removing repository content by opening an issue in the [project repository](https://github.com/lic-robotics-club/lego-spike-sync-data/issues).

Removing the app from the iPad removes its locally stored settings and folder permissions from that device. Files already uploaded to GitHub are not removed automatically when the app is uninstalled.

## Children's privacy

The app is intended for use as part of supervised LIC Robotics Club activities. Parents, guardians, and club organizers should ensure that students synchronize only robotics project files and do not include personal information in project names or contents.

## Changes to this policy

This policy may be updated when the app's features or data practices change. Updates will be published in this repository with a revision history.

## Contact

Questions or privacy requests can be submitted through the [repository issue tracker](https://github.com/lic-robotics-club/lego-spike-sync-data/issues).
